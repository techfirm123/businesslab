# BusinessLab Documentation

This directory contains the product and engineering documentation
for BusinessLab.

## Documentation structure

### product/

Product vision, positioning, principles and scope.

### architecture/

Platform architecture, module boundaries, integrations and
technical decisions.

### simulation/

Simulation engine design, business rules, assumptions, events
and execution mechanics.

### ux/

User journeys, interface principles and interaction specifications.

### ai/

AI agent architecture, responsibilities, tool permissions and
orchestration.

### development/

Implementation roadmap, backlog, local setup and engineering
progress.

### development/milestones/

Completed milestone handoff documents.

## Documentation principles

1. Product and architecture decisions must be documented.
2. Implementation must follow the approved product direction.
3. Completed milestones must have a dedicated handoff document.
4. Documentation must reflect the actual implementation.
5. Tests and build results must be recorded accurately.
6. Superseded decisions must be marked rather than silently removed.
